## 🌐 خطوات النشر على GitHub Pages (أسهل وأسرع طريقة)

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في [GitHub.com](https://github.com/new).
2. سمّ المستودع مثلاً: `my-portfolio` أو `cv`.
3. اضغط على زر **uploading an existing file** واسحب كافة محتويات مجلد `سيرة ذاتية` (ملف `index.html` ومجلد `assets` وملف `README.md`) ثم اضغط **Commit changes**.
4. ادخل على **Settings** في المستودع -> ثم من القائمة الجانبية اختر **Pages**.
5. تحت قسم **Branch**، اختر `main` واضغط **Save**.
6. في غضون دقيقة واحدة سيعطيك GitHub رابط موقعك المباشر المنشور مجاناً مدى الحياة!
